## Теоретические сведения

### 1. Бизнес-процессы

**Бизнес-процесс** — последовательность действий, ограниченная началом и окончанием и направленная на получение заданного результата.

Основные элементы:
- Цель/результат (выход)
- Владелец бизнес-процесса
- Исполнители
- Вход бизнес-процесса
- Начало, окончание, применяемые ресурсы, шаги, описание

### 2. Рекомендации по работе с бизнес-процессами

Категории бизнес-процессов:
- **Основные** — добавляют ценность бизнесу.
- **Обеспечивающие** — поддерживающие процессы.

Критерии выделения:
1. Различие в целях.
2. Бизнес-процесс должен получать результат.

Порядок работ: определить область (as is/to be), декомпозиция, выделение категорий, рассмотрение основных, затем обеспечивающих.

### 3. BPMN-диаграмма

BPMN (Business Process Model and Notation) — язык моделирования бизнес-процессов.

Виды диаграмм:
- Процесс (Process Diagram)
- Взаимодействие (Collaboration Diagram)
- Хореография (Choreography Diagram)
- Диалог (Conversation Diagram)

Базовые объекты: Event, Activity, Gateway, Flow, Data, Artefact, Swimline/Pool.
