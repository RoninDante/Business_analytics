## Теоретические сведения

### 1. Основные понятия

- **REST** — архитектурный стиль для обеспечения стандартов взаимодействия между компьютерными системами.
- **Формат представления данных**: XML, JSON, Binary.
- **Протокол передачи данных** — совокупность соглашений, определяющих порядок обмена.
- **Транспорт** — протоколы передачи данных по сети.
- **HTTP-глаголы**: GET, POST, PUT, DELETE.
- **API** — описание способа взаимодействия программных систем.

### 2. Документация

В документации отражаются:
- синтаксис запроса и ответа;
- примеры;
- описание входных и выходных параметров.

### 3. Маппинг

Маппинг — сопоставление полей данных в разных источниках хранения и передачи данных. Следует учитывать:
- идентификатор поля;
- бизнесовое наименование/описание;
- тип данных;
- размерность;
- обязательность;
- комментарии.

### 4. Обработка ошибок

При получении некорректных сообщений система-получатель должна сообщить об ошибке. Проверяются:
- тип данных;
- размерность;
- обязательность;
- наличие в справочнике;
- логические условия.
