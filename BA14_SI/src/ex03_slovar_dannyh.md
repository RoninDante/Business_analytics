# Exercise 03 — Определение словаря данных

**Задача 2. Доставка заказов.** Словарь по потокам: что везём, в каком каркасе, какие поля.

---

## Поток 1. Данные о заказах (унифицированный ввод)

**Назначение:** учёт заказа в платформе доставки.  
**Направление:** в систему.

### Структура (блоки и вложенность)

| Блок | Уровень вложенности | Обязательность | Содержание |
|------|---------------------|----------------|------------|
| Заказ (корень) | 0 | Обязательный | Идентификация и сроки |
| Партнёр | 1 внутри Заказ | Обязательный | Кто заказал доставку (магазин, кафе) |
| Точка комплектации | 1 | Обязательный | Откуда забирать |
| Точка доставки | 1 | Обязательный | Куда везти |
| Позиции заказа | 1 | Условно обязательный: либо ≥1 строка, либо флаг «состав не детализируем» | Состав, если его реально ведут |
| Пожелания по доставке | 1 | Необязательный | Окно времени, комментарий |

### Атрибуты

| Блок | Атрибут | Тип данных | Длина (текст) | Обязательность | Ограничения / условия |
|------|---------|------------|---------------|----------------|----------------------|
| Заказ | external_order_id | Строка | 64 | Да | Уникален в связке с partner_id за период |
| Заказ | placed_at | Дата-время (ISO 8601) | — | Да | Не позже текущего момента более чем на заданный допуск |
| Заказ | desired_delivery_window_start | Дата-время | — | Нет | Должен быть < desired_delivery_window_end |
| Заказ | desired_delivery_window_end | Дата-время | — | Нет | — |
| Партнёр | partner_id | Строка (UUID или код) | 36 | Да | Из справочника партнёров |
| Партнёр | partner_name | Строка | 200 | Нет | Кэш названия для экрана, если справочник недоступен |
| Точка комплектации | pickup_location_id | Строка | 36 | Да | Ссылка на справочник адресов |
| Точка комплектации | pickup_address_text | Строка | 500 | Нет | Если нет id — обязательен текст |
| Точка доставки | delivery_lat | Число (десятичное) | — | Да* | *Если нет геокодинга — обязателен address_line |
| Точка доставки | delivery_lon | Число (десятичное) | — | Да* | Диапазон широты/долготы для региона |
| Точка доставки | delivery_address_line | Строка | 500 | Условно | Обязателен без координат |
| Точка доставки | delivery_contact_phone | Строка | 20 | Да | Формат E.164 или локальный шаблон |
| Позиции | line_no | Целое | — | Да | Порядковый номер |
| Позиции | sku_or_name | Строка | 120 | Да | — |
| Позиции | quantity | Число | — | Да | > 0 |
| Пожелания | courier_comment | Строка | 1000 | Нет | — |
