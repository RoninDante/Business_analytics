## Теоретические сведения

### 1. Стандарты и основные понятия

- **SOAP** — протокол обмена структурированными сообщениями в формате XML.
- **XML** — язык разметки документов.
- **XSD** — язык описания структуры XML-документа.
- **WSDL** — язык описания веб-сервисов (операции, входные/выходные сообщения, адрес сервиса).

### 2. Два подхода к разработке

- **CODE-FIRST** — сначала разрабатывается код, затем генерируются документы.
- **CONTRACT-FIRST** — элементы кода генерируются на основе готовых документов.

## Описание задач

### Задача 4. SOAP сервисы — Клуб любителей домашних животных

Айтишники города N организовали «Клуб любителей животных» и решили создать базу данных членов клуба и их питомцев. Разработаны два веб-сервиса с протоколом SOAP. Первый — для ведения списка членов клуба, второй — для ведения списка питомцев. Web-сервисы описаны WSDL-документами `member.wsdl` и `pet.wsdl`.
