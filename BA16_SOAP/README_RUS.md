# Проект 16: Интеграция веб-сервисами SOAP

## Введение

Рассматривается взаимодействие веб-сервисами посредством протокола SOAP, язык разметки XML, язык описания структуры XML-документа (XSD), язык описания веб-сервисов WSDL.

## Литература

1. Стандарты W3C: [XML](https://www.w3schools.com/xml/default.asp), [XSD](https://www.w3schools.com/xml/schema_intro.asp), [WSDL](https://www.w3schools.com/xml/xml_wsdl.asp), [SOAP](https://www.w3schools.com/xml/xml_soap.asp)
2. Ильдар Хабибуллин. Самоучитель XML (глава 1, глава 3)

## Теоретические сведения

**SOAP** — протокол обмена структурированными сообщениями в формате XML. **XML** — язык разметки. **XSD** — язык описания структуры XML-документа. **WSDL** — язык описания веб-сервисов (операции, входные/выходные сообщения, адрес). **Подходы:** CODE-FIRST (сначала код, потом документы), CONTRACT-FIRST (сначала документы, потом код).

## Описание задач

### Задача 4. SOAP сервисы — Клуб любителей домашних животных

Айтишники города N организовали «Клуб любителей животных» и создали базу данных членов клуба и их питомцев. Разработаны два веб-сервиса с протоколом SOAP. Первый — для ведения списка членов клуба, второй — для ведения списка питомцев. Сервисы описаны WSDL-документами `member.wsdl` и `pet.wsdl`.
