## Теоретические сведения

### 1. Немного о жизненном цикле сущности

Для отслеживания состояния экземпляра сущности применяется понятие «жизненный цикл объекта» — ряд состояний (статусов), которые проходит экземпляр объекта. В сущность добавляется атрибут «Статус».

### 2. Справочники

Справочники описывают данные, используемые для заполнения в других сущностях. Справочники разрабатываются перед основными смысловыми объектами.

### 3. Описание объекта

Описание объекта должно содержать:
1. Назначение.
2. Атрибуты, их описание.
3. Связи с другими объектами (ER-диаграмма или диаграмма классов).
4. Действия (операции) над экземплярами.
5. Роли и права доступа.
6. Жизненный цикл.
7. Визуализация.
8. Интерфейсы обмена.
9. Отчеты.

### 4. Назначение объекта

Краткое описание целевого назначения сущности: что содержит, в каких бизнес-процессах участвует, откуда поступает информация, для чего применяется.

### 5. Атрибуты объекта

Для описания атрибута указывается:
- мнемоника;
- наименование;
- краткое описание;
- тип;
- обязательность;
- значение по умолчанию;
- предполагаемая длина;
- комментарии.

### 6. Диаграмма классов

Диаграмма классов — структурная диаграмма UML, демонстрирующая структуру иерархии классов системы, атрибутов, методов, интерфейсов и взаимосвязей.

Диаграмма классов состоит из трех разделов:
- Верхняя часть: имя класса (с заглавной буквы, жирный шрифт).
- Средняя часть: поля (атрибуты) класса (с маленькой буквы).
- Нижняя часть: методы класса (с маленькой буквы).
