## 1. Контекст UC02

**Актор:** менеджер барбершопа.
**Цель:** зарегистрировать запись клиента на выбранную услугу к выбранному мастеру в свободном временно́м слоте.
**Триггер:** клиент звонит/подходит к менеджеру и просит записать его.

### Основной поток (main flow)

1. Менеджер открывает форму «Новая запись» в админ-интерфейсе.
2. Менеджер вводит или выбирает клиента (ФИО, телефон).
3. Менеджер выбирает услугу из справочника.
4. Менеджер выбирает мастера, выполняющего эту услугу.
5. Менеджер выбирает свободный временно́й слот из расписания мастера.
6. Менеджер выбирает предпочтительный канал связи клиента (TG / WhatsApp / VK / SMS).
7. Менеджер нажимает **«Сохранить»**.
8. Система валидирует данные, закрепляет слот за мастером, создаёт запись.
9. Система планирует авто-напоминания согласно действующему расписанию (см. `FRQ009`).

### Постусловия основного потока

- Слот больше не отображается в списке свободных.
- Запись видна в расписании мастера и в списке записей менеджера.
- В очереди напоминаний появляется задача для выбранного канала (см. `FRQ002`).

### Менеджер-персона (для всех кейсов)

| Поле                    | Значение                               |
| ----------------------- | -------------------------------------- |
| Сущность                | Сотрудник (Employee)                   |

| Роль (Role)             | Менеджер (manager)                     |
| Логин                   | `sidorovamp`                           |
| Рабочая точка           | Барбершоп «Центральный»                |

## 4. TC-UC02-P-02 — Запись нового (незарегистрированного) клиента

| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1. ID**             | `TC-UC02-P-02`                                                                                                                                   |
| **2. Название**       | Создание клиента «на лету» и запись его на свободный слот                                                                                        |
| **3. Приоритет**      | Средний                                                                                                                                          |
| **4. Предусловие**    | 1) Менеджер `sidorovamp` авторизован. 2) В БД **нет** клиента с телефоном `+7 999 000 11 22`. 3) У мастера «Кузнецов В.С.» на `20.04.2026` есть свободный слот `15:30` для услуги «Детская стрижка». |

| **6. Шаги**           | 1. В поле «Клиент» ввести `Новиков К. Л.`, телефон `+7 999 000 11 22` → в выпадающем списке выбрать действие «+ Создать нового клиента». 2. Заполнить чекбокс «Согласие на обработку ПДн (152-ФЗ)». 3. «Услуга» = «Детская стрижка». 4. «Мастер» = «Кузнецов В.С.». 5. Слот = `20.04.2026 15:30`. 6. «Канал связи» = «WhatsApp». 7. Нажать «Сохранить». |
| **7. Ожидаемый результат (ОР)** | a) Ответ: «Запись #M создана, клиент Новиков К.Л. добавлен в базу». b) В таблице `clients` появилась запись с `phone = +7 999 000 11 22`. c) Слот `15:30` у Кузнецова стал занят. d) В очереди напоминаний — задача для канала `whatsapp`. |
| **8. Постусловие**    | `DELETE /api/bookings/M` → `DELETE /api/clients/{id_нового}`; убедиться, что слот `15:30` снова свободен и в `clients` нет тестового номера.     |
| **9. Фактический результат (ФР)** | _Pending — заполнить после прогона._                                                                                                             |
| **10. Повторяемость** | ✓ Постусловие возвращает БД к исходному состоянию (и запись, и вновь созданный клиент удаляются).                                                |
| **11. Атомарность**   | ✓ Использует отдельного мастера (Кузнецов) и отдельный слот (15:30); клиент создаётся и удаляется в пределах кейса.                              |
