## Теоретические сведения

### 1. Сценарии и варианты использования (UseCase)

**UseCase (UC)** — описание взаимодействия участников с системой.

Описание UC включает:
- Заголовок (уникальное название, глагол + существительное)
- Действующие лица (Actor, Primary actor, Заинтересованная сторона)
- Цель, назначение
- Область действия (Scope)
- Предусловия
- Триггер
- Постусловия (минимальные гарантии, гарантии успеха)
- Поток событий (основной, альтернативный, исключения)
- Дополнительные параметры

### 2. Рекомендации

1. Описывайте UC в бизнесовых понятиях.
2. Ограничивайте границы UC достижением цели.
3. Используйте простые предложения.
4. Собирайте в один шаг все данные, передаваемые в одном направлении.
5. Применяйте «Система подтверждает...» вместо «Система проверяет...».
6. Сложные взаимодействия сводите к 4 шагам транзакции.

### 3. Связи вариантов использования

- **Включение (include)** — общая функциональность для нескольких UC.
- **Расширение (extend)** — вставка в UC дополнительной функциональности.
