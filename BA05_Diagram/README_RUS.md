## Теоретические сведения

### 1. Предметная область

**Предметная область (domain)** — часть реального мира, рассматриваемая в некоторых пределах. Это обстоятельства и условия, которые влияют на построение/изменение системы, находятся под влиянием системы, способствуют пониманию системы.

### 2. Выделение сущностей и действий над ними

Порядок выделения сущностей:
1. Выделение кандидатов в сущности (существительные и пары с глаголами в тексте).
2. Выделение сущностей.
3. Определение ключевых свойств каждой сущности.
4. Определение связей между сущностями (1:1, 1:М, М:1, М:М).
5. Сопоставление атрибутов с сущностями.
6. Назначение ключей и степени нормализации.
7. Завершение, проверка модели данных.

### 3. Проверка сущностей по CRUD

Методика CRUD. Каждый экземпляр сущности должен быть проверен на:
- создание (Create);
- чтение (Read);
- обновление (Update);
- удаление (Delete).

### 4. Словарь данных

**Словарь данных (Data Dictionary)** — техника, позволяющая описать данные в бизнес-терминах, а также содержащая другие сведения о данных: типы и форматы данных, детализацию структур данных, ограничения.

| | Глоссарий | Словарь данных |
|---|---|---|
| Что содержит | Термины, сокращения, понятия, бизнес-описание | Понятия, бизнес-описание, техническое описание данных |
| Состав | Атомарные понятия | Может содержать составные элементы |

### 5. Построение ER-диаграммы

Модели данных:
- **Концептуальная модель** — основные сущности, связи.
- **Логическая модель** — сущности, атрибуты, ключи, взаимосвязи.
- **Физическая модель** — таблицы, столбцы, связи, свойства БД.

## Задания

### Exercise 00 — Выявление сущностей (Entity detection)

**Для каждой задачи:**

1. Определите не менее 7 сущностей, с которыми будет работать система.
2. Определите для каждой сущности название, назначение, основные атрибуты.
3. Укажите свои ответы в turn-in файле `ex00_<префикс продукта>_entity.xlsx`.

### Exercise 01 — Проверка сущности по CRUD (Entity validation by CRUD)

**Для задачи 1:**

1. Для каждой сущности проведите проверку полноты операций по CRUD.
2. Отразите в таблице роли и действия.
3. Запишите свои ответы в turn-in файле `ex01_<префикс продукта>_crud.xlsx`.

### Exercise 02 — Построение словаря данных (Building a data dictionary)

**Для каждой задачи:**

1. Постройте словарь данных.
2. Включите название сущности, мнемонику, описание, тип данных, обязательность.
3. Разместите таблицу в turn-in файле `ex02_<префикс продукта>_dict.xxx` (xxx — расширение файла).

### Exercise 03 — Построение логической модели данных (Building a logical data model)

**Для каждой задачи:**

1. Постройте ER-диаграмму — логическую модель данных.
2. Включите выбранные сущности, справочники, развязочные таблицы.
3. Укажите множественность связей, опишите связи глаголами.
4. Разместите диаграмму в turn-in файле `ex03_<префикс продукта>_model.xxx` (xxx — расширение файла).
