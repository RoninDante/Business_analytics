# Объект: "Платеж"
### Цель: Показать жизненный цикл платежа за услугу
### Область: to be

| Предыдущее состояние | Последующее состояние | Событие/Действие | Инициатор | Условия |
|---------------------|----------------------|------------------|-----------|---------|
| - | Ожидает оплаты | Клиент записался на услугу | Клиент | - |
| Ожидает оплаты | Оплачен | Клиент произвел оплату | Клиент | - |
| Ожидает оплаты | Отменен | Клиент отменил запись | Клиент | - |
| Оплачен | Возвращен | Клиент отменил запись | Менеджер | До начала услуги |
| Оплачен | Завершен | Услуга оказана | Система | - |
| Отменен | [*] | Система удалила запись | Система | - |
| Возвращен | [*] | Система закрыла операцию | Система | - |
| Завершен | [*] | Система архивировала платеж | Система | - |

### Начало: Клиент записался на услугу
### Окончание: Платеж завершен или отменен

# Объект: "Уведомление"
### Цель: Показать статусы уведомлений клиентам
### Область: to be

| Предыдущее состояние | Последующее состояние | Событие/Действие | Инициатор | Условия |
|---------------------|----------------------|------------------|-----------|---------|
| - | Создано | Система сгенерировала уведомление | Система | - |
| Создано | Отправлено | Система отправила клиенту | Система | - |
| Создано | Отменено | Уведомление больше не актуально | Система | - |
| Отправлено | Доставлено | Клиент получил уведомление | Система | - |
| Отправлено | Не доставлено | Ошибка отправки | Система | - |
| Доставлено | Прочитано | Клиент прочитал уведомление | Клиент | - |
| Прочитано | [*] | Система очистила историю | Система | Через 30 дней |
| Не доставлено | [*] | Система удалила failed уведомление | Система | - |
| Отменено | [*] | Система удалила отмененное уведомление | Система | - |

### Начало: Создание уведомления
### Окончание: Удаление уведомления
