## Теоретические сведения

### 1. Способы выявления требований

Выявление требований — совместный с заинтересованными сторонами аналитический процесс. Требования следует обнаружить, собрать, установить.

Способы выявления требований:
1. Анализ документации
2. Анализ контекста системы
3. Изучение подобных систем
4. Глоссарий
5. Интервью
6. Фокус-группы
7. Опрос
8. Семинар
9. Мозговой штурм
10. Прототипирование
11. Моделирование бизнес-процессов

### 2. Интервью, опрос, ролевая игра

- **Интервью** — техника выявления потребностей через непосредственное общение.
- **Опрос/анкетирование** — техника выявления требований систематическим способом за короткое время.
- **Ролевая игра** — техника, поощряющая участников к совместному достижению цели.

### 3. Мозговой штурм, семинар

- **Мозговой штурм** — эффективный способ решения проблем, стимулирует творческую активность команды.
- **Семинар** — мероприятие для достижения выбранной цели и выработки согласия.

### 4. Как описать бизнес-требования

Бизнес-требования описывают основные преимущества, которые новая система предоставит заказчикам, пользователям, организации.

При описании бизнес-требований следует отразить:
1. Проблему(-ы)
2. Окружение, предусловия
3. Возможности
4. Бизнес-цели
5. Границы системы
6. Критерии, метрики успеха

### 5. Роли проекта и их функции

Роли и их действия, выполняемые в проекте, определяются и уточняются в рамках ролевой игры, мозгового штурма, семинара.

### Exercise 00 — Ролевая игра (Role-playing game)

**Для задачи 2:**
