# Портфолио: проекты по бизнес-аналитике

## Введение

В рамках практической подготовки были выполнены 17 проектов, охватывающих основные аспекты деятельности бизнес-аналитика и системного аналитика. В ходе работы создавались реальные артефакты, используемые в ежедневной практике анализа требований, моделирования и проектирования информационных систем.

## Инструменты

- **Моделирование диаграмм:** Draw.io, Balsamiq, Figma, Lucidchart
- **Управление задачами и требованиями:** WEEEK, Jira, Trello
- **Тестирование API:** SoapUI, Postman
- **Документирование:** Markdown, Excel, Word
- **Система контроля версий:** Git

## Проекты

**Проект 00.** Роль и функции ИТ-аналитика в команде разработки. Жизненный цикл ПО, ролевой состав, декомпозиция.

**Проект 01.** Заинтересованные стороны (стейкхолдеры). Выявление стейкхолдеров, луковичная диаграмма, анализ потребностей.

**Проект 02.** Требования. Виды требований, модели as is и to be, контекстная диаграмма.

**Проект 03.** Способы выявления требований. Интервью, мозговой штурм, семинары. Документ «Видение».

**Проект 04.** Предметная область и информационная модель. Выделение сущностей, CRUD, ER-диаграмма.

**Проект 05.** Модели и диаграммы. DFD, Swimlane, диаграмма и таблица состояний.

**Проект 06.** Моделирование бизнес-процессов. BPMN, выделение процессов, ревизия артефактов.

**Проект 07.** Пользовательские истории (User Stories). US, критерии приемки, тестовые сценарии.

**Проект 08.** Сценарии использования (Use Cases). UC, потоки, связи include/extend.

**Проект 09.** База данных и словарь данных. Классы, атрибуты, диаграмма классов UML.

**Проект 10.** Проектирование функциональных требований. CRUD+, статусные модели, права доступа.

**Проект 11.** Проектирование пользовательского взаимодействия. Wireframe, сценарии, контроли.

**Проект 12.** Нефункциональные требования. Атрибуты качества: производительность, доступность, безопасность.

**Проект 13.** Управление требованиями, качеством, задачами. Идентификация, статусы, тест-кейсы.

**Проект 14.** Интеграция ИТ-систем. Критерии и стили интеграции.

**Проект 15.** Интеграция веб-сервисами REST. HTTP-методы, API, маппинг.

**Проект 16.** Интеграция веб-сервисами SOAP. XML, WSDL, обратное проектирование.
